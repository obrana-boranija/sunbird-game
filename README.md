# sunbird-game

The public website for **Sunbird**, a one-tap flying game — and the host
for the privacy policy both app stores require to be reachable before
review.

- `index.html` — the landing page
- `privacy/index.html` — the privacy policy, generated from
  `store/PRIVACY.md` in the (private) game repository

`store/PRIVACY.md` is the source of truth. When it changes, this page
has to be regenerated and pushed in the same sitting: the store listing
points here, and a policy that disagrees with the app is a review
problem.

Published with GitHub Pages from `main`.
